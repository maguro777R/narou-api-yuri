# 百合の観測室

百合に関係する Web 小説の、題材や読者の反応を眺めるサイトです。小説を書く際に「最近どんなキーワードが並んでいるか」「気になる作品を読んでみよう」と考えるための手がかりにします。

**公開先:** [百合の観測室](https://maguro777r.github.io/narou-api-yuri/) / **更新状況:** [GitHub Actions](https://github.com/maguro777R/narou-api-yuri/actions)

毎週火曜の朝 6:23 ごろ（日本時間）、API から作品情報を取得し、GitHub Pages を更新する構成です。自分のパソコンを起動しておく必要はありません。初回の有効化は [運用ガイド](docs/OPERATIONS.md) に記載しています。

## 見られるもの

- 一般向けと、ノクターンノベルズの男性向け R18 を分けた集計。
- 百合候補の週間ポイント上位最大 500 作品で多いキーワード。
- 短編・連載中・完結済みの割合、文字数の分布と中央値。
- 一般向けのジャンル別の内訳と、条件に合う上位 5 作品へのリンク。

R18 のページは 18 歳以上の方が対象です。年齢確認後に集計と作品情報を表示します。

## 「百合」「男性向け」の意味

「ガールズラブ」が設定されている作品、または作者のキーワードに「百合」を含む作品を、**百合候補** として集めます。両方に該当しても 1 作品として数えます。百合が脇の要素の作品、TS 百合、他の恋愛要素を含む作品も入ることがあります。

一般向け API には男性向けの分類がありません。一般向けを男性向けと断定せず、**男性向けの掲載区分があるノクターンを別ページにする** 方針です。実際の読者の性別は分かりません。

ジャンル・形式の切り替えは、取得済みの上位作品を絞るものです。週間ポイントが 0 の作品は集計しません。なろうの全作品の割合や、題材の成功確率を示す数字ではありません。初版に前週比や急上昇の判定はありません。

## 手元で画面を見る

Python 3.12 以降を使います。集計・画面生成に追加ライブラリは不要です。GitHub では Python 3.13 を使います。

```sh
# 架空データで画面を作る。API にはアクセスしません。
python3 -m scripts.build --demo

# http://127.0.0.1:8000/ を開く。
python3 -m http.server 8000 --bind 127.0.0.1 --directory site

# 数え方とページ生成のテスト。
python3 -m unittest discover -v
node --check web/app.js
```

運用者がなろうに登録済みで、18 歳以上であることを確認した後は、`python3 -m scripts.build --live` で実データを取得できます。通常 4 回のリクエストを、2 秒以上の間隔で送ります。生データはメモリ上で集計した後に破棄します。生成した `site/` は Git に登録しません。

| 場所 | 役割 |
| --- | --- |
| `scripts/narou.py` | 百合候補を取得し、対象外の混入や重複を確認する |
| `scripts/analysis.py` | 作品数・中央値・キーワードを数える |
| `scripts/render.py` / `web/` | 図表、作品紹介、切り替え、年齢確認を作る |
| `scripts/build.py` | 一般向けと R18 のページをまとめて作る |
| `scripts/freshness.py` | 両ページの取得日時を確認する |
| `tests/` | 数え間違い・安全な表示・更新停止対策を検証する |
| `.github/workflows/` | GitHub 上のテスト・定期取得・公開の手順 |

作品本文・あらすじの取得、原データや JSON・CSV の再配布、取得情報を AI に送る機能はありません。非商用で運用し、広告やアフィリエイトは置きません。
