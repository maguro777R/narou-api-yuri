# なろう観測室

「小説家になろう」で、いまどんな作品が読者の反応を集めているのかを眺めるためのサイトです。Web 小説を書く際の、題材探しや読書の入口として使います。

**サイト:** [なろう観測室](https://maguro777r.github.io/narou-api-test/)

毎週火曜の朝 6:23 ごろ（日本時間）に、なろう小説 API から作品情報を取得し、GitHub Pages のページを更新します。自分のパソコンを起動しておく必要はありません。

## 何が見られるか

- 全ジャンルの週間ポイント上位 500 作品の傾向。
- 20 ジャンルそれぞれの週間ポイント上位 100 作品の傾向。
- 作者がつけたキーワード、短編・連載中・完結済みの割合、文字数の分布。
- 条件ごとに上位 5 作品の紹介と、作品ページへのリンク。

ジャンルと作品の形式を切り替えて使います。週間ポイントが 0 の作品は集計しません。形式の切り替えは、取得した上位作品の中を絞るものです。例えば「推理・短編」は、推理の上位 100 作品に含まれる短編を指します。

初版では **毎週更新する現在の傾向** を表示します。過去のデータを蓄積していないため、前週比・急上昇・年間推移は表示しません。

## このリポジトリの読み方

- [PLAN.md](PLAN.md): 何を、どの順番で作るか。
- [運用ガイド](docs/OPERATIONS.md): 手動更新、困ったとき、公開を止めたいとき。
- [数字の読み方](docs/METHODOLOGY.md): 対象・数え方・わからないこと。
- コミット履歴: 何のために変更したか。小さな変更ごとに日本語で記録します。

集計対象は週間ポイントの上位作品です。なろう全作品の割合や、作品が成功する確率を示すものではありません。

出典: [なろう小説 API](https://dev.syosetu.com/man/api/) / [利用ガイドライン](https://dev.syosetu.com/site/guideline/)

## 仕組みを変えたい人へ

必要なのは Python 3.12 以降です。集計・画面生成に追加ライブラリは使いません。CI では Python 3.13 を使います。

```sh
# 架空データで画面を作る。API にアクセスしません。
python3 -m scripts.build --demo

# プレビューを起動して http://127.0.0.1:8000/ を開く。
python3 -m http.server 8000 --bind 127.0.0.1 --directory site

# テストを実行する。
python3 -m unittest discover -v
```

実データを使うときは、なろうにユーザ登録済みで利用条件を満たしていることを確認してから `python3 -m scripts.build --live` を実行します。通常 21 回のリクエストで、最低 40 秒ほどかかります。生データはメモリ上で集計した後に破棄し、`site/` に閲覧用の HTML だけを生成します。`site/` は Git に登録しません。

| 場所 | 役割 |
| --- | --- |
| `scripts/narou.py` | 必要な項目を取得し、欠けたデータを検出する |
| `scripts/analysis.py` | 件数・中央値・キーワードを数える |
| `scripts/render.py` | 集計を読むページを作る |
| `web/` | 見た目と画面の切り替え |
| `scripts/freshness.py` | 公開ページが古くなっていないか確認する |
| `tests/` | 数え間違いや期限切れなどの確認 |
| `.github/workflows/` | GitHub での定期実行・テスト・公開の手順 |

作品本文・あらすじ、JSON / CSV のデータセット、認証情報は、このリポジトリにも公開ページにも含めません。問い合わせ先は [GitHub Issues](https://github.com/maguro777R/narou-api-test/issues) です。
