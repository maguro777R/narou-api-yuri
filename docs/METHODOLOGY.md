# 数字の読み方

## どの作品を見ているか

一般向けの「小説家になろう」と、男性向け R18 の「ノクターンノベルズ」を別々に扱います。二つのサイトの件数やポイントを合算したランキングは作りません。

各サイトで、次の二つを週間ポイントの高い順に最大 500 作品ずつ取得します。

1. 作者が作品要素に「ガールズラブ」を設定している作品。
2. 作者のキーワードに「百合」を含む作品。

二つの検索で取得した同じ作品は N コードでまとめ、上位最大 500 作品に絞ります。週間ポイントが 1 以上の作品だけを数えます。検索の一致件数は重複するため、足して「百合の総作品数」とは表示しません。

「百合ハーレム」「TS百合」などもキーワードの部分一致で対象になります。「百合なし」のような否定表現でも一致することがあります。本文を読んだ分類ではなく、女性同士の恋愛が中心か、作中で成立するかは判定しません。逆に、ガールズラブ設定も百合キーワードもない作品は拾えません。

## 男性向けといえる範囲

一般向け API に、男性向けかどうかを示す項目はありません。作者名、作品名、ジャンルから読者の性別を推測しません。

ノクターンは公式に男性向けとされる掲載区分です。R18 API ではこの区分だけを取得し、ムーンライト・ミッドナイトが混じった応答は公開せずエラーにします。ただし掲載区分は、実際に読んだ人の性別を示すものではありません。

R18 API には一般向けと同じジャンル項目がないため、R18 に恋愛・ファンタジーなどのジャンルを作って付けません。

## 数字を比べるとき

- **週間ポイント:** ランキング集計時点から過去 7 日以内に新たに登録された評価・ブックマークに基づく API の値です。閲覧数、読者数、累計ポイント、前回取得との差ではありません。
- **中央値:** 小さい順に並べた中央の値です。作品数が偶数なら中央の 2 件を平均します。画面は整数に丸めて表示します。対象がない場合は `—` です。
- **文字数:** 取得時点で公開されている作品全体の文字数です。連載途中なら将来の完成時の長さとは違います。文字数帯の上限は含みません。例えば 5 万字は「5〜10 万字」に入ります。
- **作品形式:** 短編・連載中・完結済みを API の区分から読みます。連載中と短編の長さを直接比べず、形式を切り替えると見やすくなります。
- **割合:** その画面で絞った対象作品数が分母です。20 作品未満では数作品の違いで割合が大きく変わるため、画面にも注意書きを出します。

ジャンル・形式の切り替えは、取得した百合候補の上位最大 500 作品の中を絞ります。例えば「現実世界〔恋愛〕・短編」が少なくても、そのジャンル全体の百合短編が少ないという意味ではありません。

## キーワードの数え方

作者が登録したキーワードを空白で分割し、全角・半角と英字の大小を揃えます。同じ作品内の同じ語は 1 回だけ数えます。

共通の選択条件である「百合」「ガールズラブ」「GL」と、注意タグの「R15」「R18」「残酷な描写あり」は完全一致で除外します。「学園百合」「TS百合」などの複合語や応募タグは残します。機械学習による意味の分類や同義語の統合はしません。

1 作品に複数の語があるため、割合の合計が 100% を超えることがあります。上位 12 語を表示し、同数なら文字順で並べます。

## 取得方法と限界

- 各検索を 2 秒以上空けて行います。通常は 2 サイト × 2 条件の計 4 回です。
- 同じ作品の値が取得中に変わった場合は、後の検索の応答を採用します。完全に同時刻の観測ではありません。
- ポイント同点は、取得できた候補の中で N コード順にします。API の上位 500 件の境界に同点作品がある場合、対象が入れ替わることがあります。
- 0 ポイントの作品は対象にしません。原データを長期保存しないため、前週比・急上昇・年間推移は表示しません。
- 「多いキーワード」を「その題材を選べば読まれる確率」と解釈することはできません。選ばれなかった作品や投稿全体との比較ではないためです。
- 本文・あらすじは取得しません。公開するのは図表と上位作品の紹介で、原データの配布やダウンロード機能はありません。

[R18 Atom](https://dev.syosetu.com/xman/atom/) は新着エピソード用で、同じ作品が複数回載ることがあります。ポイントやキーワードの週次集計には、両方の JSON API を使います。
