# 数字の読み方

## 集計対象

全ジャンルについて `order=weeklypoint&lim=500` で取得します。別に、現在の 20 ジャンルそれぞれについて `genre=ジャンル番号&order=weeklypoint&lim=100` で取得します。どちらも週間ポイントが 1 以上の作品だけを集計します。

全体上位とジャンル別上位を足し合わせません。同じ作品が複数の取得結果に出ても、それぞれ独立した集計です。旧「ノンジャンル」と「未選択」は全体上位に入ることがありますが、個別に取得する 20 ジャンルには含めません。

「短編」「連載中」「完結済み」は取得後の絞り込みです。形式別の上位 100 作品を API で取り直すわけではありません。集計件数が少ないときほど、わずかな作品の入れ替わりで割合が変わります。

同点の並び順は API に従います。100 位や 500 位と同点の全作品を取得する設計ではありません。また、21 回の取得には時間差があり、同一瞬間の厳密な比較ではありません。

## 各数字

| 表示 | 数え方・読み方 |
| --- | --- |
| 週間ポイント | API の `weekly_point`。ランキング集計時点から過去 7 日以内の新しい評価・ブックマークが対象 |
| 観測した作品 | 取得上限の中で、週間ポイントと表示条件を満たした作品数 |
| ジャンル・形式の割合 | その区分の作品数 ÷ 表示中の観測作品数 |
| キーワードの割合 | その語を登録した作品数 ÷ 表示中の観測作品数 |
| 文字数 | 取得時点で公開されている本文全体の API 上の文字数。1 話の長さではない |
| 中央値 | 値を小さい順に並べた真ん中。偶数件なら中央の 2 つの平均。表示は整数に丸める |

文字数の区間は、1 万字未満、1 万字以上 5 万字未満、5 万字以上 10 万字未満、10 万字以上 30 万字未満、30 万字以上です。完結前の作品も含むため、連載の最終的な長さはわかりません。

## キーワードの扱い

作者が登録したキーワードを空白で分けます。全角・半角を NFKC 正規化し、英字の大小を揃え、同じ作品内の同じ語は 1 回として数えます。「R15」「残酷な描写あり」は題材としての比較から除外します。

応募企画名などは削除せず含めます。似た意味の語をまとめる処理や AI 分析は行いません。本文・あらすじ・タイトルから語を抽出した数ではありません。複数キーワードが付くため、割合の合計は 100% にはなりません。

## 推測してはいけないこと

- この割合を、なろう全体に投稿された作品の割合として読むこと。
- ポイントが多いことを、閲覧者数が多いことと同じだとみなすこと。
- よくあるキーワードを選べば成功する、と因果関係を決めること。
- 今回の値だけから、前週より増えた・減ったと判断すること。

タイトルやキーワードだけでは、実際の内容や読み味はわかりません。作品紹介は、本文を読みに行く入口として使います。

## データと利用条件

初版は現在の結果を更新する方式です。取得した JSON をファイルに保存せず、本文とあらすじも取得しません。公開するのは図表と各条件の上位 5 作品の紹介ページで、JSON / CSV のデータセット配布はありません。生成したページはソースコードの Git 履歴に含めません。

自動公開に必要な HTML 等だけを GitHub Actions の一時成果物として渡し、保持期間を 1 日にしています。公開ページは毎週置き換え、長く更新できない場合は休止案内に変えます。過去の作品情報や統計の履歴は蓄積しません。

非商用の図表・作品紹介として設計しており、公式が挙げるランキング・紹介用途を参考にしています。加工済みデータセットの再配布も禁止されているため、用途を広げる際は個別に条件を確認してください。この設計が運営の個別承認を受けたという意味ではありません。
